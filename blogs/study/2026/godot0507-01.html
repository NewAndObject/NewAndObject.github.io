# Godot引擎版本变化概览

Godot引擎是一款开源的跨平台游戏引擎，自2014年开源以来，经历了多个重要版本的迭代。以下是各主要版本的核心变化。

# Godot 4.6（2026年1月）

主题：专注于工作流优化

# 核心特性

  • 新编辑器主题"Modern"：默认启用，提供更简洁现代的界面
  • Jolt Physics成为默认物理引擎：从实验性升级为正式版，适用于所有新的3D项目
  • 可移动停靠面板：统一了停靠系统，面板可以在编辑器的各个位置拖动和浮动
  • 全新的IK框架：引入IKModifier3D类，支持TwoBoneIK3D、SplineIK3D、FABRIK3D、CCDIK3D、JacobianIK3D等多种求解器
  • 唯一Node ID：节点现在拥有唯一的内部ID，重构场景时引用更安全

# 其他改进

  • SSR（屏幕空间反射）全面优化
  • 场景瓦片可旋转（90度增量）
  • 3D选择与变换模式分离
  • GridMap使用Bresenham线算法绘制
  • 新增视图轴旋转控制柄
  • Control节点支持pivot_offset_ratio（比例枢轴点）
  • 鼠标和键盘焦点分离
  • MarginContainer节点可视化边距反馈
  • 资源拖拽到脚本编辑器自动创建@export变量
  • 测试游戏时可动态调整运行速度
  • Quick Open对话框支持实时预览
  • 动画编辑器时间线可拖拽调整长度
  • Patch PCK支持增量编码
  • 支持自定义键盘快捷键
  • 手柄LED灯光控制基础
  • 纹理导入速度提升（Betsy GPU转换）
  • 网格LOD组件裁剪优化
  • Glow混合改进（色调映射前）
  • AgX色调映射参数可配置
  • 反射和辐射探针使用八面体地图
  • Mobile渲染器支持材质去色带和HDR精度
  • 修复Mali和Adreno GPU崩溃问题
  • CSV翻译支持context和plural列
  • C#翻译解析器支持
  • XR编辑器支持Android XR设备
  • 原生OpenXR 1.1支持
  • OpenXR空间实体支持
  • Android导出支持scrcpy镜像
  • Android编辑器Gradle构建支持
  • Android存储访问框架（SAF）
  • Windows默认Direct3D 12
  • 网格自动生成碰撞形状
  • GDExtension参数和返回值标记为required
  • JSON格式的GDExtension接口
  • GDScript调试器添加Step Out按钮
  • C++追踪分析器支持（Tracy、Perfetto）
  • GDScript LSP改进BBCode转Markdown
  • 字符串占位符高亮显示

# Godot 4.5（2025年9月）

主题：让梦想触手可及

# 核心特性

  • 模板缓冲区支持：实现穿孔、遮罩等高级渲染效果
  • 屏幕阅读器支持：基于AccessKit，为视障用户提供无障碍访问
  • 脚本回溯追踪：即使在Release版本也能追踪错误来源
  • 自定义日志器：可拦截日志消息，用于游戏内bug报告
  • Shader Baker：预编译着色器，大幅减少加载时间（Apple/Windows平台最高20倍）
  • 国际化实时预览：在编辑器视口中直接预览翻译效果

# 其他改进

  • TileMapLayer物理合并单元格形状为更大碰撞体
  • duplicate_deep()方法用于数组、字典和资源
  • 构建配置检测扩展
  • 游戏静音切换按钮
  • 资源拖拽按UID预加载（Ctrl键）
  • 运行时可选择多个远程节点
  • 编辑器语言切换无需重启
  • Inspector分区可切换
  • 导出变量为Variant类型
  • 脚本颜色选择器预览
  • EditorScripts通过命令面板执行
  • "粘贴为唯一"选项
  • 项目管理器可直接复制项目
  • 信号连接自动附加源
  • Animation Player质量提升（框选、自动切线、字母排序、过滤）
  • HiDPI图标优化
  • FoldableContainer折叠容器
  • Label堆叠效果支持
  • Control节点递归覆盖鼠标和焦点行为
  • Android 16KB页面支持
  • Android边缘到边缘显示
  • Android摄像头源支持
  • 移动端光照贴图烘焙和UV展开
  • Linux原生Wayland子窗口支持
  • macOS游戏窗口嵌入
  • 支持导出visionOS（Apple Vision Pro）
  • Windows导出无需rcedit
  • WebAssembly SIMD支持
  • GDScript可变参数（...args）
  • GDScript抽象类和方法
  • GDExtension主循环回调
  • SDL3游戏手柄输入驱动
  • 专用2D导航服务器
  • 导航区域异步处理
  • SceneTree 3D物理插值
  • 环境光镜面遮挡
  • 弯曲法线贴图支持
  • SMAA 1x抗锯齿
  • Mobile渲染器半精度浮点格式

# Godot 4.4（2025年3月）

主题：统一体验

# 核心特性

  • Jolt Physics集成：作为实验性功能内置
  • 嵌入游戏窗口：游戏可在编辑器内嵌入运行
  • 交互式游戏内编辑：运行时可点击和移动场景元素
  • Android编辑器XR支持：Meta Quest 3/3S/Pro支持
  • Ubershaders：预编译着色器，消除着色器卡顿
  • 3D物理插值：解耦物理帧和显示帧率，减少抖动
  • AgX色调映射：电影级渲染效果
  • 类型化字典：支持指定键和值的类型
  • 通用UID支持：资源引用不再依赖文件路径

# 其他改进

  • 全局优化（性能提升）
  • Manifold库替代CSG实现
  • Curve域扩展到[0,1]之外
  • 临时文件和目录工具
  • SceneTree系统重构
  • 3D对象对齐吸附
  • Inspector收藏夹
  • Camera3D预览
  • GDScript工具提示
  • 表达式评估器（REPL）
  • LightmapGI阴影遮罩
  • 持久化窗口状态
  • 可视化着色器改进
  • 场景启动优化（最高3倍）
  • 所有分析器自动启动
  • 首次导入无错误
  • @export_tool_button注解
  • Android编辑器导出支持
  • JavaClassWrapper修复
  • AndroidFilePicker支持
  • Swappy帧 pacing库
  • 主题图标
  • Linux摄像头支持
  • Metal渲染后端（Apple Silicon）
  • Apple游戏手柄改进
  • .NET 8.0支持
  • .NET Android支持（全ABI）
  • LookAtModifier3D
  • SpringBoneSimulator3D（物理骨骼）
  • 动画标记
  • 运行时WAV文件加载
  • Betsy纹理压缩器
  • glTF自定义属性动画扩展
  • 异步导航
  • 导航系统重构
  • 碰撞形状自定义颜色
  • 光照贴图双三次采样和透明度
  • 顶点着色
  • 2D批处理（所有渲染器）
  • 渲染驱动降级
  • 阴影投射掩码
  • 2D着色器实例uniforms
  • 3D粒子系统发射形状可视化

# Godot 4.3（2024年8月）

# 核心特性

  • 2D物理插值：解耦物理帧和显示帧率
  • GDScript 2.1：支持lambda表达式、静态类型推断改进
  • TileMap重构：新的TileMapLayer系统
  • 多窗口支持：编辑器支持多窗口
  • 新的3D后处理效果：SSIL（屏幕空间间接光）、GI探针改进
  • AnimationTree改进：更强大的动画状态机

# Godot 4.2（2023年11月）

# 核心特性

  • C# .NET 7支持
  • 新的资源预览器
  • GDExtension：替代GDNative，更稳定的C/C++扩展
  • 2D骨骼动画改进
  • 新的调试器功能
  • 导航系统改进
  • Vulkan Mobile渲染器优化
  • Android导出改进

# Godot 4.1（2023年7月）

# 核心特性

  • 编辑器性能优化
  • 新的2D光照系统
  • 动画系统改进
  • C#支持增强
  • VR/XR支持改进
  • 新的导入选项
  • Web平台支持改进

# Godot 4.0（2023年3月）

主题：全新架构，重大变革

# 核心特性

  • 全新3D渲染器：基于Vulkan，支持Forward+、Mobile、Compatibility三种渲染模式
  • GDScript 2.0：全新的解析器，性能提升数倍
  • 新的3D物理引擎：Godot Physics 4.0
  • SceneTree重构：更高效的节点处理
  • 新的UI系统：改进的Control节点
  • SDFGI：屏幕空间距离场全局光照
  • VoxelGI：体素全局光照
  • 新的动画系统：AnimationTree改进
  • C#支持：从Mono迁移到.NET
  • 新的导入管线
  • WebAssembly支持
  • 新的调试工具
  • 超过12,000个PR合并
