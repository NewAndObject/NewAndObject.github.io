如何安装ase2ttf（使用rustup.rs安装方式）和如何使用ase2ttf在asprite转换ttf格式文件

如何安装ase2ttf（使用rustup.rs安装方式）和如何使用ase2ttf在asprite转换ttf格式文件

悯 2026-07-15 15:30:00 godotaspritettf

# 1.简介

ase2ttf 是一个可以将 Aseprite 文件（.aseprite）直接转换为 TrueType 字体（.ttf）的命令行工具。它非常适合制作像素风格字体，无需复杂的字体编辑软件

# 2.安装 Rust 环境（通过 rustup.rs）

ase2ttf 是通过 Rust 的包管理器 Cargo 安装的，因此需要先安装 Rust 开发环境。

# 第一步：下载安装程序

访问 Rust 官网 下载地址，下载 rustup-init.exe

# 3.安装 ase2ttf

打开命令提示符（cmd）或 PowerShell，执行以下命令

cargo install ase2ttf
1

Cargo 会自动下载、编译并安装 ase2ttf。安装完成后，验证是否成功：

ase2ttf --version
1

# 4.在 Aseprite 中准备字体文件

ase2ttf 对 Aseprite 源文件有特定要求：

  1. 一个字符一个图层：为字体中的每一个字符创建一个独立的图层。

  2. 图层命名规则：每个图层的名称必须以 U+ 开头，后面紧跟该字符的 Unicode 码点。例如：

    • 字母 A → 图层命名为 U+0041

    • 数字 5 → 图层命名为 U+0035

    • 空格 → 图层命名为 U+0020

    • 感叹号 ! → 图层命名为 U+0021

提示：可以在 Unicode 字符表 等网站上查询字符的码点。

  1. 图层顺序：ase2ttf 会按照图层在 Aseprite 中的排列顺序（从左上到右下）来分配字符。

  2. 保存文件：完成后，将文件保存为 .aseprite 格式。

  3. Unicode查询网站网站

# 6.案例

ase2ttf -o my_font.ttf --family "MyPixelFont" --glyph-width 6 --glyph-height 6 --trim "my_aseprite_file.aseprite"
1

这条命令会将 my_aseprite_file.aseprite 转换为 my_font.ttf，字体名称为 MyPixelFont，字符大小为 6*6 像素，并自动修剪空白

ase2ttf -o number_abc1.ttf --family="MSJPixelFont" --glyph-width=5 --glyph-height=5 "E:\11.读书工作生活\我的生活\1.程序员\1.游戏开发\GoDot\项目\2.2D\山海桃源项目\GiteeCode\shanhai-taoyuan\09_Resources\myfont\精灵-0007.aseprite"

# 教训

用asprite创建图层时，不需要一个字符创建一个图层，因为你这样创建用 ase2ttf 转换后，回出现转换的ttf文件报错：不是有效的字体文字。
比如数字的码点是U+0030，你就创建一个U+0030的图层放数字，如果你还需要创建小写字母，就再创建一个名称为：U+0061 的图层绘画小写字母。
另外，不知道为什么，图层的码点不需要和码点表对齐，比如，你创建完成一个数字图层，下一个就是创建小写字母图层，但是图层名称不能用U+0061（小写a的码表），只能往这个码点往前移动，在于是多少，只能边改边看了。
