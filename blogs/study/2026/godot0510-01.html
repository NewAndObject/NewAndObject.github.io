像素游戏斜向移动"太空步"问题

vuePress-theme-reco 悯    2020 - 2026

像素游戏斜向移动"太空步"问题

悯 2026-05-10 15:30:00 godotgame

# 问题

按住右+下时，输入方向 = (0.707, 0.707)，角度刚好在 45° 边界上。

手一抖，角度在 43°~47° 波动 → 方向在 RIGHT/DOWN 之间频繁跳 → 太空步。

# 算法

# 一行代码解决
var direction_id : int = int( round( ( direction + cardinal_direction * 0.1 ).angle() / TAU * 4 ) )
1
2
  • direction — 当前输入方向（归一化向量）
  • cardinal_direction — 上一次确认的朝向
  • TAU = 2π — 整圆弧度

# 核心：磁滞偏置

direction + cardinal_direction × 0.1
1

把上一次朝向的 10% "拖拽力"加到当前输入上，制造偏向历史方向的偏移。

# 举例 1：当前朝 DOWN，斜向按 DOWN+RIGHT

当前朝向：cardinal_direction = (0, 1)  ← 朝下
输入：    direction          = (0.707, 0.707)  ← 右+下，45°
1
2

# 分步计算

步骤 计算 结果
① 偏置 (0, 1) × 0.1 (0, 0.1)
② 合成 (0.707, 0.707) + (0, 0.1) (0.707, 0.807)
③ 角度 atan2(0.807, 0.707) 0.852 rad = 48.8°
④ 归一化 0.852 ÷ 6.283 × 4 0.542
⑤ 四舍五入 round(0.542) 1
⑥ 取方向 DIR_4[1] ↓ DOWN

原始输入 45°，偏置后变成 48.8°，仍落在 DOWN 区间 → 方向不变 ✅

# 如果输入角度轻微抖动（43°~47°）

输入43° + 偏置 → ~47° → round=1 → DOWN
输入45° + 偏置 → ~49° → round=1 → DOWN  
输入47° + 偏置 → ~51° → round=1 → DOWN
1
2
3

全部判定为 DOWN → 方向稳定 ✅

# 举例 2：当前朝 DOWN，改按纯 RIGHT

当前朝向：cardinal_direction = (0, 1)
输入：    direction          = (1, 0)  ← 纯右，0°
1
2
步骤 计算 结果
① 偏置 (0, 1) × 0.1 (0, 0.1)
② 合成 (1, 0) + (0, 0.1) (1, 0.1)
③ 角度 atan2(0.1, 1.0) 0.1 rad = 5.7°
④ 归一化 0.1 ÷ 6.283 × 4 0.064
⑤ 四舍五入 round(0.064) 0
⑥ 取方向 DIR_4[0] → RIGHT

输入 0°，偏置后 5.7°。玩家意图足够强（纯右），方向正常切换为 RIGHT ✅

# 举例 3：当前朝 RIGHT，斜向按 RIGHT+DOWN

当前朝向：cardinal_direction = (1, 0)  ← 朝右
输入：    direction          = (0.707, 0.707)
1
2
步骤 计算 结果
① 偏置 (1, 0) × 0.1 (0.1, 0)
② 合成 (0.707, 0.707) + (0.1, 0) (0.807, 0.707)
③ 角度 atan2(0.707, 0.807) 0.718 rad = 41.1°
④ 归一化 0.718 ÷ 6.283 × 4 0.457
⑤ 四舍五入 round(0.457) 0
⑥ 取方向 DIR_4[0] → RIGHT

偏置把 45° 拉低到 41.1°，落在 RIGHT 区间 → 方向不变 ✅

# 关于"偏置后还是 45°"的问题

会不会出现偏置后刚好 45°，正好卡在边界上？

会，但没关系。拿举例 1 来说：

偏置后角度 45° ←→ 归一化值 = 45°/360° × 4 = 0.5
1
round(0.5) = 1    ← 四舍五入取偶，Godot 中 round(0.5) = 1
DIR_4[1] = DOWN
1
2

即使偏置后刚好 45°，也会被确定性地归到 DOWN。而且下帧开始，cardinal_direction 变成 DOWN，偏置方向固定为朝下，角度会进一步被拉开。

帧 1：偏置后恰好 45° → round(0.5)=1 → 选 DOWN
帧 2：cardinal_direction = DOWN → 偏置朝下 → 偏置后 > 45° → 继续 DOWN
     （偏置方向固定后，不会回到 45° 边界了）
1
2
3

只要方向确定过一次，后续帧的偏置方向固定，角度就不会再回到边界上。 这形成了一种"自锁"效果。

# 总结

direction + cardinal_direction × 0.1
1
  • 0.1 = 10% 的历史方向拖拽力
  • 创造 ~12° 的磁滞带 = 防抖缓冲区
  • 即使恰好卡 45° 边界，round(0.5) 确定性取 1 + 后续自锁，不会跳变
  • 1 行代码，0 个额外变量，完美消除太空步
