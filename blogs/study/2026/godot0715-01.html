godot引擎源代码编译和导出模板加密-3.6版本为例，4x版本差不多

悯 2026-06-30 15:30:00 godot

# godot引擎源代码编译官方教程链接

  1. 安装git
  2. 安装python，设置环境变量（这样就可以在cmd窗口执行命令了，cmd命令：sysdm.cpl,然后找到高级>环境变量>系统变量>Path>添加一个python的exe文件路径和pip的exe路径在python的exe的script文件夹下）
  3. 使用python安装Scons（python -m pip install scons）
    • scons官方教程
  4. 使用git下载对应版本的godot源代码
  5. 使用cmd在godot源代码文件夹下命令：scons platform=windows。编译成功后，生成的可执行文件会放在源码根目录下的 bin/ 文件夹里。文件名会根据你选择的平台和目标有所不同，例如 godot.windows.editor.dev.x86_64.exe。

# 生成加密导出模板，官方教程链接

  1. 使用OpenSSL下载链接或专门网站生成16进制的AES的加密密钥加密网站链接
    • OpenSSL生成命令：openssl rand -hex 32 > godot.gdkey
    • 这条命令会生成一个密钥并保存到 godot.gdkey 文件中
    • 查看并记录密钥：用记事本打开 godot.gdkey 文件，复制里面的64位字符串（如 aeb1bc...f64890f）。请务必保管好这个密钥，不要泄露
  2. 打开cmd窗口到godot源代码目录下，执行设置导出模板密钥命令：set SCRIPT_AES256_ENCRYPTION_KEY=你生成的64位密钥字符串
  3. 在godot源代码目录下的cmd窗口，执行生成导出模板命令：scons platform=windows tools=no target=release bits=64
  4. 编译成功后，生成的文件会出现在源码根目录下的 bin 文件夹中：godot.windows.opt.64.exe、godot.windows.opt.64.exp、godot.windows.opt.64.lib、godot.windows.opt.64.pdb
    • godot.windows.opt.64.exe 这个文件就是导出模板
    • .exp 和 .lib：链接器使用的导出库文件，用于后续编译其他模块或插件（正常导出游戏用不到）
    • pdb：程序调试数据库文件，包含调试符号信息，用于在出现崩溃时定位问题（导出游戏时不需要随包分发）
  5. 如何在 Godot 编辑器中使用这个模板
    • 打开你的 Godot 项目，点击顶部菜单 项目 -> 导出。
    • 在导出预设列表中，选择你的 Windows 导出预设（如果没有，先添加一个）。
    • 在右侧的导出设置面板中，找到 “自定义模板” 部分：
      1. 勾选 “使用自定义导出模板”。
      2. 在 “发布” 一栏中，点击文件夹图标，浏览并选择你编译出来的 godot.windows.opt.64.exe。
    • 点击 “导出项目”，生成的游戏包就会使用你刚刚编译的这个模板了。
    • 会生成：.exe和.pck文件，

# 开发 官方教程链接

  • 安装vs studio和对应的环境（.Net 桌面开发、使用c++的桌面开发、使用c++的移动开发、使用c++的游戏开发）即可开发源代码
  • cmd窗口在godot源代码目录下执行命令：scons p=windows vsproj=yes。生成.sln文件，双击即可开始开发代码

# 反编译软件

  • 下载路径
  • 操作方法
    • 第一步：点击左上角的-RE Tools
    • 第二步：点击RE Tools里的Recove Project
    • 第三步：选择生成的游戏exe文件

# 备注

  • 加密必须使用自定义加密模板，并且在导出设置里的脚本里输入密钥，如果两个少操作一个都会导致加密失败，结果还是未加密的游戏

  • 4.x版本可能需要执行以下命令才能生成引擎和导出模板（确保你在Godot源码根目录下，另外这两个是外网的，可能需要一点手段）：
    • python misc\scripts\install_accesskit.py
    • python misc\scripts\install_d3d12_sdk_windows.py
  • 4.x版本导出模板命令是：
    • scons platform=windows target=template_release arch=x86_64
  • 每次生成加密导出模板都需要执行命令（set SCRIPT_AES256_ENCRYPTION_KEY=你生成的64位密钥字符串），一但关闭cmd命令窗口，就无法进行加密了，因为密钥只是临时存在该窗口下的缓存中
  • 网站生成密钥解释
    • iv：godot导出里的初始向量种子
    • salt：godot导出安卓导出的选项》APK扩展》盐的值
    • key：godot导出里的加密的加密密钥
